# 💡 Brainstorming et Idée Retenue - WebTest AI

## L'idée retenue : WebTest AI
Un assistant intelligent qui analyse le code source **HTML5, CSS3 et JavaScript** pour générer automatiquement des audits de qualité, des vérifications d'accessibilité et des tests unitaires adaptés au développement web et web mobile.

## Pourquoi je l'ai choisie :
1. **Enthousiasme :** J'aime l'idée de transformer une tâche ingrate et répétitive (écrire les tests et vérifier la conformité) en un processus automatisé qui me donne un sentiment de "super-pouvoir" sur mon propre code.
2. **Apprentissage :** C'est un excellent moyen de progresser en compréhension algorithmique et web. Pour que l'IA génère de bons tests, je dois apprendre à structurer mon code pour qu'il soit propre et testable, ce qui va drastiquement améliorer ma qualité de développement.
3. **Utilité / Faisabilité :** C'est un outil très concret qui répond à un problème réel (les bugs d'intégration et les régressions front-end). Techniquement, c'est réalisable avec les APIs d'IA (comme OpenAI ou Mistral) car elles excellent dans l'analyse de code textuel.

## Ce qui me fait peur / Les défis :
Le principal défi sera de garantir la pertinence des tests générés pour du code visuel (HTML/CSS) où il n'y a pas de logique pure, et de gérer correctement l'analyse de fichiers multiples (HTML liés à du JS/CSS).

## La première chose à faire :
Écrire une fonction JavaScript simple et un extrait HTML/CSS associé, puis les tester manuellement via un prompt d'IA pour évaluer la qualité des tests et audits générés.
