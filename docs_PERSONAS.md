# 👥 Personas - WebTest AI

## Persona 1 : Thomas, l'Apprenti Développeur Web
- **Profil :** Étudiant en formation Développeur Web et Web Mobile (DWWM), 26 ans.
- **Contexte :** Il maîtrise les bases du HTML5, CSS3 et JavaScript, mais a tendance à oublier d'écrire des tests ou à négliger l'accessibilité (a11y) par manque de temps.
- **Besoins :** Avoir un retour rapide sur la qualité de son code, comprendre ses erreurs et apprendre les bonnes pratiques de tests sans passer des heures à configurer des environnements complexes.
- **Frustrations :** Perdre du temps à chercher pourquoi un composant est mal structuré ou pourquoi un script JavaScript échoue sur un cas limite.

## Persona 2 : Sarah, la Développeur Front-End Junior en reconversion
- **Profil :** En poste en agence web depuis 6 mois, elle code des sites vitrines et applications web légères en Vanilla JS / HTML / CSS.
- **Contexte :** Elle doit livrer du code propre rapidement à ses clients, mais gère seule la partie tests et qualité de ses pages web.
- **Besoins :** Automatiser les vérifications de base (sémantique HTML, cohérence CSS, tests unitaires JS) pour s'assurer qu'aucun bug visuel ou logique ne passe en production.
- **Frustrations :** La charge mentale liée à la relecture manuelle de lignes de code répétitives avant chaque livraison.
