# WebTest AI

Bienvenue sur le dépôt de **WebTest AI**, un outil de développement propulsé par l'IA, conçu spécifiquement pour les étudiant·e·s et développeur·euse·s en formation (notamment sur la stack **HTML5, CSS3 et JavaScript**).

## 🚀 Présentation du projet
**WebTest AI** analyse le code source de vos projets web front-end (HTML, CSS et JavaScript Vanilla) pour générer automatiquement :
- Des audits de sémantique et d'accessibilité (HTML).
- Des vérifications de robustesse et de cohérence (CSS3).
- Des tests unitaires et de comportement du DOM (JavaScript).

## 📂 Structure du dépôt
- `README.md` : Présentation globale du projet.
- `docs/` : Dossier contenant la documentation de conception.
  - `IDEAS.md` : Le brainstorming et le choix de l'idée.
  - `PERSONAS.md` : Description des utilisateurs cibles.
  - `USER_STORIES.md` : Fonctionnalités clés et besoins utilisateurs.

## 🛠️ Comment cloner et utiliser le projet ?

Pour cloner ce dépôt en local sur votre machine, exécutez la commande suivante dans votre terminal :

```bash
git clone https://github.com/votre-nom-utilisateur/vibecoding-ia-tool.git
cd vibecoding-ia-tool
```

*(Ce dépôt constitue la base de conception de l'outil avant l'intégration des maquettes et du code source aux prochaines étapes).*
