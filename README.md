# 🤖 WebTest AI

> Un assistant de développement propulsé par l'IA, conçu spécifiquement pour les étudiant·e·s et développeur·euse·s en formation sur la stack **HTML5, CSS3 et JavaScript**.

---

## 🚀 Présentation du projet
**WebTest AI** analyse le code source de vos projets web front-end pour générer automatiquement :
- Des audits de sémantique et d'accessibilité (HTML).
- Des vérifications de robustesse et de cohérence (CSS3).
- Des tests unitaires et de comportement du DOM (JavaScript).

---

## 📂 Architecture et structure du dépôt

Le projet est organisé de la manière suivante :

| Dossier / Fichier | Description |
| :--- | :--- |
| `specs/` | Contient le cahier des charges (`cahier_des_charges.md`) et les choix de conception. |
| `docs/` | Documentation connexe (brainstorming `IDEAS.md`, personas et user stories). |
| `prompts/` | Ressources de prompt engineering utilisées pour guider l'IA. |
| `front/` | Code source de l'interface utilisateur (`index.html`, `style.css`, `script.js`). |
| `README.md` | Documentation principale du projet. |
