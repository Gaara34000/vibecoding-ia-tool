# 📋 User Stories - WebTest AI

Voici les fonctionnalités essentielles de l'outil décrites sous forme de User Stories :

## User Story 1 : Audit sémantique et accessibilité HTML
- **En tant que** développeur en formation,
- **Je veux** soumettre mon fichier HTML à l'IA pour qu'elle analyse sa sémantique et détecte les erreurs d'accessibilité (ex: absence d'attributs `alt`, balises mal imbriquées),
- **Afin de** corriger mes erreurs rapidement et concevoir des pages web conformes aux standards du web.

## User Story 2 : Vérification de la cohérence et robustesse CSS
- **En tant que** développeur front-end,
- **Je veux** que l'IA analyse mes feuilles de style CSS3 pour détecter les propriétés obsolètes ou les règles redondantes,
- **Afin de** maintenir un code propre et éviter des comportements inattendus sur mobile.

## User Story 3 : Génération automatique de tests unitaires JavaScript
- **En tant qu'** utilisateur de l'outil,
- **Je veux** sélectionner une fonction JavaScript pure et obtenir instantanément un fichier de test unitaire (Jest/Mocha) couvrant les cas limites (*edge cases*),
- **Afin de** sécuriser mon code contre les régressions sans perdre de temps à rédiger les tests manuellement.
